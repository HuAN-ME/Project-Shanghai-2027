# Project Shanghai 2027

**From Windows to Linux.**  
**From Network Engineering to DevOps Engineer.**  
**Destination: Shanghai.**

# About

Project Shanghai 2027 is a long-term DevOps engineering practice project.

The goal is to build practical DevOps capabilities through continuous learning, hands-on labs, automation, and real-world infrastructure practice.

Focus areas:

- Linux Administration
- Containerization
- Kubernetes
- CI/CD
- Cloud Native Technologies
- Infrastructure Automation
